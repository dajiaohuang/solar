# Cross-layer audit and improvements — 2026-09-10

This audit builds on `76fce92` (shared evaluation and streamed histories).
It follows data from source artifacts and indexes through Go evaluation,
HTTP transport, browser persistence, worker publication, rendering and native
tile caching. It is a code and regression-test audit, not an independent
scientific certification or a production load test.

## Implemented findings

| Area | Finding and correction | Evidence |
| --- | --- | --- |
| Elliptic propagation | Invalid angular inputs could produce non-finite states; Go now rejects all non-finite elements, negative mean motion and overflow, while Web rejects invalid angles. | Go accuracy tests; Web Kepler accuracy tests |
| Near-periapsis accuracy | A fixed equation-residual threshold could accept an inaccurate root at high eccentricity. Both solvers now use safeguarded Newton iteration, stable evaluation of E−sin(E), and a relative root stopping criterion. Orbital-plane expressions avoid cancellation. | Five independent 80-digit roots, conservation of energy/angular momentum, existing scientific oracles |
| Event detection | Flat non-extremal tracks were repeatedly rescanned. Plateaus now advance in linear time; plateaus touching endpoints are excluded, and refinement rejects non-finite model values. | Sample-access counting and invalid-model regressions |
| Scientific worker delivery | Workers embedded verbose audit records and eagerly initialized fallback identity tables. Build-time execution indexes retain ordered file IDs, hashes, URLs, byte counts, windows and solution dependencies. Separate worker plugins prevent fallback imports. | Projection equality tests, emitted-worker size gate, production builds |
| SPK Type 21 | Three temporary heap allocations per evaluation; an unused legacy evaluator also duplicated the numerical implementation with different offsets. Use bounded request-local stack arrays and remove the dead evaluator. | Existing CSPICE fixtures and allocation benchmarks |
| Inventory indexing | A manifest could understate total records before index construction; retained term arrays were sized to all postings. Validate totals before opening shards and allocate retained arrays by unique term count. | Invalid-count-before-I/O and capacity tests |
| HTTP input boundary | `LimitReader` could turn an oversized request into an accepted valid JSON prefix. Share `MaxBytesReader`-backed decoding across plan, tile, window and legacy trajectory requests. | Exact-limit and trailing-payload tests |
| Browser persistence | Blocked/denied IndexedDB access could prevent network delivery or leak a late connection. Opens fail softly, have a bounded wait, and close late connections. Cache pruning retains metadata instead of all buffers. | Storage denial, blocked-open and concurrent-transfer tests |
| Validated cache delivery | Concurrent raw downloads were duplicated. In-flight requests coalesce, consumers receive independent transferable buffers, and format validators run before persistence. Invalid cached payloads are removed. | Buffer-transfer isolation, retry and parser tests |
| Catalog data organization | Failed searches could be cached as empty results; rejected samples remained poisoned; sample keys lacked full artifact identity. Evict failures, distinguish errors from zero matches, capture release roots, and validate elliptic binary rows before persistence. | Catalog cache/recovery regressions |
| Service Worker | Arbitrary same-origin GETs, including dynamic APIs, could be replayed as shell assets. Cache only the installed shell allowlist; do not overwrite an old build's offline HTML with another generation. | Cache-policy unit tests and real offline-shell browser tests |
| Event worker lifecycle | A queued result could overwrite a newer cached result or cancelled task. Invalidate request ownership before every run/cancel and require worker ownership at publication. | Deterministic stale-callback test |
| Interaction | IME Enter/Escape could select or close search prematurely; failed next-page requests discarded the directory; keyboard controls overlapped the distance ribbon. Guard composition keys, retain the explicitly labelled verified page for retry, and separate the controls. | Desktop/mobile browser tests and screenshot inspection |
| Calendar display | Date labels depended on host timezone and recreated a formatter every call. Reuse a UTC formatter consistent with the date input. | Near-midnight UTC regression |
| Android persistence | Reopening a cache could subtract a corrupt file before counting it, understating retained bytes. Reconcile into an independent total before eviction. | Java compilation and five JUnit decoder/cache tests |

Raw scientific JSON, original kernels and reference fixtures remain unchanged.
The complete source manifest is still packaged as `ephemeris-manifest.json`;
the compact execution index does not replace it. Two-body fallback propagation
remains explicitly approximate. No extra ephemeris coverage is claimed.

## Measured results

Same local Pages-profile build, uncompressed JavaScript sizes:

| Worker | Before, approximately | After |
| --- | ---: | ---: |
| Trajectory | 1,086,340 bytes | 266,585 bytes |
| Mission/porkchop | 1,089,120 bytes | 269,354 bytes |
| Conjunction | 1,089,430 bytes | 269,669 bytes |

Each is about 75% smaller. Build validation now enforces a 512 KiB ceiling
for these workers. This measures delivery size, not device frame rate.

The resident SPK Type 21 fixtures went from three allocations per evaluation
(400 bytes for the synthetic fixture, 496 for Eris) to zero. Timings varied
with host load: early post-change runs were slower, later runs were faster.
No isolated end-to-end speedup is inferred from those timings.

## Verification

- Go: 142 tests in 11 packages; vet passed.
- Web CI: lint, 595 unit tests passed (9 optional tests skipped), 122/122
  scientific checks, and production build passed.
- Desktop/mobile end-to-end suite: 188 passed, two skipped.
- Real Go-to-Web window/tile tests: three passed, one inventory test skipped.
  The optional source-inventory test requires `-inventory-dir` and
  `SOLAR_TEST_INVENTORY_ID` identifying Ceres; a backend URL alone does not
  assert that an audited inventory is loaded.
- Android decoder/cache: compiled directly with Java and passed five JUnit
  tests. Native source/packaging checks passed. This is not an Android app
  build or physical-device validation.

Reproduce the main checks with `npm run ci`, `go test ./cmd/... ./internal/...`,
`go vet ./cmd/... ./internal/...`, and `npx playwright test --workers=2`.
The SPK microbenchmark is
`go test ./internal/spk -run '^$' -bench BenchmarkEvaluationCancellationCheckpoints -benchmem`.

## Limits and remaining work

The local checkout has no pinned asteroid `dataset-version.json`. Therefore
the dataset-inclusive preview suite cannot start; the preview shell can be
built with `SOLAR_ATLAS_PRODUCT_PROFILE=preview SOLAR_ATLAS_INCLUDE_DATASET=0`.
That shell build passed. A preview subset passed ten tests; two navigation
tests failed because they expect the absent 8,000-row dataset card. Those
failures remain recorded and are not counted as a passing preview suite.
The real pinned-belt preview check needs the original dataset and has not
been substituted with synthetic scientific data.

Go's race detector remains unavailable without a CGO C compiler. iOS and
complete Android app compilation, physical-device profiling, and full source
inventory startup profiling were not performed. The larger main-thread
evidence chunk still triggers Vite's size warning; it was not hidden by
raising the warning threshold. Mobile time controls still use horizontal
scrolling on narrow screens. Scientific offline data is not promised by the
shell cache; it requires an explicit verified data cache. Durable background
jobs and the other architectural phases in the
[shared-compute document](./shared-compute-refactor.md) remain separate work.

The review also inspected the source snapshot/build pipeline, current-state
validation and streaming contracts, rendering scheduling, and iOS cache/service
boundaries. Existing source-identity, hash, frame, epoch, explicit-missing and
publication checks remain in place. These observations do not establish that
every possible defect in those subsystems has been eliminated.

## Method references

The elliptic-only boundary is consistent with the input distinctions in
[NAIF's conic-state documentation](https://naif.jpl.nasa.gov/pub/naif/toolkit_docs/C/cspice/conics_c.html).
High-precision root references were generated independently using mpmath 1.3.0,
80 decimal digits, exact binary64 input conversion, and bisection on [0, π].
They validate numerical roots, not the physical fidelity of a two-body model.
Connection lifecycle behavior follows the
[IndexedDB specification](https://www.w3.org/TR/IndexedDB/).
Production worker isolation uses Vite's separately configured
[worker plugins](https://vite.dev/config/worker-options.html#worker-plugins).
