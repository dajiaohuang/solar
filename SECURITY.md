# Security policy

## Supported versions

Security fixes target the current deployment and the latest `0.9.x` source on `main`. Older static deployments and locally retained builds are not maintained.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository from the **Security → Advisories → Report a vulnerability** page. Include the affected URL or commit, reproduction steps, expected impact, and any suggested mitigation. Do not open a public issue for an unpatched vulnerability or include real credentials, private datasets, or personal information.

Scientific-model disagreements and upstream-data errors are not security vulnerabilities; use the dedicated scientific-correctness or data-error issue template instead.

Solar Atlas is an educational visualization. It must not be relied on for navigation, operational ephemerides, collision warning, or impact-risk decisions.
