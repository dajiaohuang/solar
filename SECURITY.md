# Security policy

## Supported versions

Security fixes target the current `main` branch and the production deployment built from it. Older commits, superseded static deployments, and locally retained builds are not maintained.

## Reporting a vulnerability

Please use [GitHub's private vulnerability reporting](https://github.com/dajiaohuang/solar/security/advisories/new) for this repository. GitHub will ask you to sign in before opening the private report form. Include the affected URL or commit, reproduction steps, expected impact, and any suggested mitigation. Do not open a public issue for an unpatched vulnerability or include real credentials, private datasets, or personal information.

Scientific-model disagreements and upstream-data errors are not security vulnerabilities; use the dedicated scientific-correctness or data-error issue template instead.

Solar Atlas is an educational visualization. It must not be relied on for navigation, operational ephemerides, collision warning, or impact-risk decisions.
